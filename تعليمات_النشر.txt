طريقة نشر النسخة الجديدة على GitHub Pages

الرابط الرسمي الجديد:
https://rj0060.github.io/r/

رابط لوحة الإدارة:
https://rj0060.github.io/r/adminhamada.html

خطوات التحديث:
1. ارفع جميع ملفات هذا المجلد إلى مستودع GitHub المسمى r، في الفرع الذي تستخدمه GitHub Pages.
2. من Settings ثم Pages تأكد أن النشر مفعل من المجلد الجذري للفرع الصحيح.
3. انتظر اكتمال نشر GitHub Pages ثم افتح الرابط الرسمي أعلاه.
4. لكسر كاش النسخة القديمة أول مرة، افتح:
   https://rj0060.github.io/r/?v=2026.09.25.1
5. افتح لوحة الإدارة من:
   https://rj0060.github.io/r/adminhamada.html?v=2026.09.25.1

مهم جداً لتشغيل إضافة عائلة جديدة:
6. انسخ محتوى Code.gs إلى مشروع Google Apps Script المرتبط بالنظام.
7. احفظ المشروع، ثم اختر Deploy > Manage deployments > Edit > New version > Deploy.
8. تأكد أن رابط Web App الناتج هو نفسه الموجود في SCRIPT_URL داخل index.html وadminhamada.html.
9. من Script Properties اضبط ADMIN_PASSWORD على كلمة مرور قوية خاصة بالإدارة.
10. من لوحة الإدارة اضغط «إنشاء/تهيئة Google Sheet والبحث السريع» مرة واحدة بعد نشر الخادم.

ملاحظات:
- إعدادات manifest وService Worker مضبوطة للعمل داخل المسار /r/ في GitHub Pages.
- رابط لوحة الإدارة يجب أن ينتهي بـ adminhamada.html لأن GitHub Pages لا يستخدم قواعد .htaccess.
- الموقع قابل للتثبيت على Android، وعلى iPhone من خيار «إضافة إلى الشاشة الرئيسية».
- عند أي تحديث مستقبلي غيّر APP_VERSION في الصفحات وCode.gs وsw.js وملف manifest معاً.
